# Roles

Name the people after the headings. One person may hold two roles. Keep the headings.

## Leads

Director, art director, producer, executive producers, and technical director. One line each for what they decide.

## Art

Environment artist, asset artist, rigger, animators, and the project coordinator. One line each for what they deliver.

## Game and support

Who writes gameplay, the import path, music, extra programming, type, repository infrastructure, and voice. Note which of these are full-time seats and which are short tasks.

## Which role writes which folder

A table of folder to primary role. Use the folders in the root README: `assets/`, `animations/`, `source/`, `addons/`, `tests/`, and `tools/`.

## How a week runs

The order of the week: what the build must show, what art and animation export, what code lands, who plays the build, and where the weekly note is written.
